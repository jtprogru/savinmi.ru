# Проекты

Подборка моих pet-проектов — небольшие утилиты и материалы, которые я пишу для себя и которыми пользуюсь сам. Все они с открытым исходным кодом, в основном на Go, собираются и публикуются через GitHub Actions.

[**srekit**](https://github.com/jtprogru/srekit)
:   Генератор текстовых артефактов для SRE: задачи, постмортемы, RFC, runbook'и и changelog'и. Помогает не начинать каждый документ с чистого листа.

[**jtsekret**](https://github.com/jtprogru/jtsekret)
:   CLI для централизованного и безопасного хранения личных секретов — паролей, OAuth-токенов, API-ключей и токенов ботов.

[**jtgpwgen**](https://github.com/jtprogru/jtgpwgen)
:   Генератор паролей с настраиваемыми классами символов и режимом запоминаемых паролей.

[**jtpost**](https://github.com/jtprogru/jtpost)
:   CLI-редактор постов для управления контент-пайплайном Telegram-канала: от идеи и черновика до запланированной публикации.

[**repo-opener**](https://github.com/jtprogru/repo-opener)
:   Маленькая утилита, которая открывает remote текущего git-репозитория в браузере по умолчанию.

[**The-Way-of-SRE**](https://github.com/jtprogru/The-Way-of-SRE)
:   Дорожная карта и подборка материалов для тех, кому интересно развиваться в направлении SRE.

[**cubic-root**](https://github.com/jtprogru/cubic-root)
:   Учебное Go-приложение по мотивам [интервью-задачи](https://jtprog.ru/interview-task-0003/): multi-stage Docker-сборка и Helm-чарт для развёртывания в Kubernetes.
